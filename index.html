    The fine print (we've read it so you don't have to)
    • Token estimate from your bill, blended at three input tokens per output token: OpenAI about $4 per million, Anthropic about $6, Google about $3.
    • An agent run re-reads its context at every step, so we count about 300k tokens per run.
    • Frontier closed models: $10 per million tokens blended. Small closed models: $2. Open-weight models on hosted APIs: $0.60, or 1.5× that for a private deployment in your cloud.
    • GPUs: $2.50 per H100-hour. About 2,500 tokens/s per GPU for a 70B-class model, and 1,200 tokens/s for frontier-size models, which need a full 8-GPU node. Never fewer than 2 GPUs.
    • People: $30k a month if you hire, $10k if platform engineers pick it up, $4k extra if you already run an inference team.
    • GPU hours actually busy: 25% for spiky traffic, 45% for mixed, 70% for 24/7.
    • Sources: Epoch AI (open models trail the frontier by about 4 months), Ramp AI Index (the top 1% of spenders pay for both), Morph, Morph on Gemini and Spheron for prices, Findstack for break-even maths.

    It's a rough guide to start a conversation, not a quote. Prices move every month.
